# Evrensel Bürokrasi Bahanesi Üreticisi

## Giriş

Bu proje, insanlık tarihinin en büyük sorunlarından biri olan **bürokrasi** ile mücadele etmek için geliştirilmiştir. Artık herhangi bir işi ertelemek için bahaneniz kalmadı diye düşünmeyin – bu program sizin için en absürt, en inandırıcı ve en gereksiz bahaneleri üretir.

**Uyarı:** Bu yazılım gerçek hayatta kullanılırsa sorumluluk kullanıcıya aittir. Biz sadece evrenin entropisini artırıyoruz.

## Özellikler

- Rastgele bürokrasi bahanesi üretme (gerçekten çalışır)
- Sonsuz döngü modu (çünkü bürokrasi de sonsuzdur)
- Gizli fonksiyonlar (asla çağırmayın, ne olur ne olmaz)
- Python ile yazılmış (evet, o kadar moderniz)

## Kurulum

1. Bu repoyu klonlayın (eğer isterseniz)
2. Python yüklü olduğundan emin olun (3.x önerilir, 2.x çalışabilir ama şikayet eder)
3. Çalıştırın:

```bash
python bahane_ureticisi.py
```

## Kullanım Örneği

```
=== EVRENSEL BÜROKRASİ BAHANESİ ÜRETİCİSİ ===
Bugünkü bahane: Dosyanız sistemde kayboldu, lütfen 3 iş günü bekleyin.
Başka bir tane mi istersiniz? (Ctrl+C ile çıkın)
```
